AUDIT REPORT FOR ALZHEIMER'S DISEASE STAGING PROJECT

A. Current pipeline
- Uses locked V1 dataset (final_400.csv) and subject-level split (splits/)
- Preprocessing: grayscale, resize, per-image z-score normalization
- Augmentation: horizontal flip, rotation ±10° (train only)
- Models: CNN2D, DenseNet2D, ViT2D (2D equivalents)
- UQ: MC Dropout, Deep Ensembles, BEDL
- Training: AdamW, class-weighted CE, val macro-F1 for checkpointing, early stopping
- Evaluation: accuracy, macro F1, per-class metrics, ROC-AUC, ECE, Brier, entropy, variance, risk-coverage, confusion matrix
- Comparative evaluation: trains 3x3=9 combinations, evaluates on test set, selects best by test performance

B. Current models
- All output 4-class logits
- CNN2D: 4 conv blocks, global avg pool, dropout
- DenseNet2D: 3 dense blocks (3 layers each), growth rate 8
- ViT2D: patch embedding, CLS token, interpolated positional encoding, transformer encoder

C. Current UQ methods
- MC Dropout: stochastic forward passes with dropout enabled
- Deep Ensembles: M independent models with different seeds
- BEDL: Dirichlet evidence-based uncertainty

D. Current evaluation
- Computes standard metrics on test set for each combination
- Uses validation set for early stopping/checkpoint selection (macro-F1)

E. Verified bugs
1. Model defaults: CNN2D, DenseNet2D, ViT2D, deep_ensembles.py have default num_classes=3 (should be 4)
2. Checkpoint reuse: comparative_evaluation.py reuses checkpoints without metadata validation
3. Test-set model selection: comparative_evaluation.py selects best combo using test set (violates critical rule)
4. Overwritten training_history.json: fixed path causes overwrites in comparative study

F. Methodological risks
1. Test-set model selection -> overoptimistic, non-reproducible
2. Moderate class: only 2 subjects -> 0 in validation, high variance
3. Small ensemble size (M=3) limits UQ quality
4. Multiple testing on test set without correction
